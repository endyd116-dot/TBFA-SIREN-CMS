# F. 응답폼·신청폼 빌더 — 행사 신청·설문을 구글폼처럼 받기

> 위치: 통합 CMS › 콘텐츠 관리 › **응답폼·신청폼 관리** (`/cms-tbfa.html#forms-builder`)
> 공개 주소: `https://tbfa.co.kr/form.html?slug=폼주소` (발행을 켜야 열림)
> 응답 조회: 목록의 «응답 N» → 응답 조회 화면 → CSV 다운로드·삭제
> 대상: 운영자·관리자(권한 «응답폼·신청폼 관리»)

운영자가 코드 없이 행사 신청·설문·이벤트 참여 폼을 만들고, 링크를 공유해 응답을 받고, 응답을 엑셀로 내려받는 기능입니다. 구글폼과 같은 쓰임새이지만 응답이 우리 DB에 쌓이고, 회원이 응답하면 회원 정보와 함께 남습니다.

---

## F-1. 폼 만들기 (3분)

1. **[+ 새 폼 만들기]**
2. **제목 / slug** — slug는 영문·숫자·`_`·`-`만. 이 값이 공개 주소가 됩니다(`form.html?slug=jeju-2026`). 한 번 공유한 뒤에는 바꾸지 마세요(옛 링크가 깨집니다).
3. **설명 / 안내 문구** — 설명은 제목 아래, 안내 문구는 응답자 화면 상단 박스에 보입니다(일정·장소·준비물 등).
4. **질문 추가** — 버튼을 눌러 질문을 쌓습니다. 종류: 텍스트 · 긴 텍스트 · 이메일 · 전화 · 숫자 · 날짜 · 드롭다운 · 단일 선택 · 다중 선택 · 응답자 파일 첨부(준비 중 — 응답 화면에는 안내 문구만 나옴). 질문마다 라벨, 필수 여부, 안내(placeholder·도움말), 선택지(드롭다운·단일·다중)를 적습니다. 순서는 각 칸의 ↑↓ 버튼으로 바꿉니다.
   - **이미지·자료 넣기(2026-11-01)** — 관리자가 포스터·안내 사진(«이미지» 블록)이나 안내문·신청서 양식 파일(«자료(파일)» 블록)을 올려 질문 사이에 배치할 수 있습니다. 아래 F-1b 참고.
   - 신청자에게 나중에 연락하려면 **이름(텍스트)·연락처(전화)** 필드는 필수로 두세요.
5. **접근** — 누구나(비회원도 응답) / 제한(링크를 가진 사람만·목록에 노출 안 됨) / 회원만(로그인 필수). «로그인 필수»를 체크하면 비회원 응답이 차단됩니다. «같은 회원의 중복 응답 허용»을 체크하지 않으면 회원은 1인 1회만 응답할 수 있습니다.
6. **정원(선택)** — 응답 정원을 적으면 그 수에 도달했을 때 접수가 자동으로 닫히고 «정원 마감 시 안내 메시지»가 보입니다.
7. **알림** — «응답 도착 시 어드민에게 인앱 알림»(기본 켬). 이메일로도 받으려면 알림 이메일 주소를 적습니다.
8. **저장** 뒤 **활성**(응답 받음)과 **발행**(공개 주소 열림)을 **둘 다 켭니다**. 공개 주소 상자에서 주소를 복사하세요.

## F-1b. 이미지·자료 블록 — 관리자가 올려서 폼 안에 배치 (2026-11-01)

질문 탭 위쪽 보라색 줄 **«+ 이미지·자료 넣기»** 에서 블록을 추가합니다. 블록은 응답을 받지 않는 안내용 칸이라 필수·응답 표·CSV에 들어가지 않습니다.

| 블록 | 올릴 수 있는 것 | 응답자 화면 |
|---|---|---|
| **이미지** | JPG·PNG·GIF·WEBP · 한 블록에 12장까지(큰 사진은 자동으로 줄여서 올라감) | 크기(크게·중간·작게)대로 표시 · 2장 이상이면 두 장씩 나란히(휴대폰은 한 줄) · 누르면 원본이 새 창으로 |
| **자료(파일)** | PDF·한글(HWP·HWPX)·워드·엑셀·파워포인트·TXT·ZIP·이미지 · 한 블록에 10개 · 파일당 100MB | 파일 종류·이름·크기와 «내려받기» 버튼 목록 |

1. **[이미지]** 또는 **[자료(파일)]** 을 누르면 맨 아래에 블록이 생깁니다.
2. **제목(선택)·설명(선택)** 을 적고, **[+ 이미지 올리기]/[+ 파일 올리기]** 로 파일을 고릅니다(여러 개 한 번에 가능).
3. 블록 안 순서는 사진의 ◀ ▶ (자료는 ↑↓)로, 빼려면 «빼기».
4. 블록 오른쪽 위 **↑↓** 로 질문 사이 원하는 자리로 옮깁니다. 맨 위로 올리면 폼 첫머리 포스터처럼 보입니다.
5. **[저장]** — 파일을 올리는 중이거나 비어 있는 블록이 있으면 저장 전에 알려 줍니다.

- 올린 파일은 공개 파일이라 폼 주소를 아는 누구나 볼·내려받을 수 있습니다. 개인정보가 든 문서는 올리지 마세요.
- 응답자가 파일을 올리는 «응답자 파일 첨부» 질문은 아직 준비 중입니다(응답 화면에는 «담당자에게 별도 안내를 받아 달라»는 문구만 나옵니다).

## F-2. 공유하기

- 복사한 주소를 문자·카톡·SNS·캠페인 글·공지에 붙여 넣습니다. 캠페인 페이지의 «참여 안내»나 소식 글에 링크로 넣는 것이 가장 자연스럽습니다.
- 접근을 «제한»으로 두면 주소를 아는 사람만 들어올 수 있고 사이트 어디에도 목록으로 노출되지 않습니다.
- 접수가 시작됐는지 확인하려면 공개 주소를 직접 열어 보세요. «발행»만 켜고 «활성»을 끄면 주소는 열리지만 «지금은 접수 중이 아닙니다»로 보입니다.

## F-3. 응답 확인·내려받기

- 목록의 **«응답 N»** 을 누르면 응답 조회 화면이 열립니다. 응답자(회원이면 이름·이메일·전화가 자동으로 붙음), 제출 시각, 각 필드의 답이 표로 보입니다.
- **[CSV 다운로드]** 로 엑셀에서 열어 정리합니다. 시험 삼아 넣은 응답은 **[삭제]** 로 지웁니다.
- 접수를 끝내려면 폼 편집에서 **«활성» 끄기**(공개 주소에 마감 안내가 보임) 또는 정원 설정을 쓰세요. «발행»까지 끄면 주소 자체가 열리지 않습니다.

## F-4. 신청자를 잠재 후원자·발송으로 이어가기 (현재 연결 상태)

- 폼 응답은 **응답 조회 화면에만** 쌓이고, 잠재 후원자 표나 발송 수신자 그룹에는 자동으로 들어가지 않습니다.
- 신청자에게 문자·카톡·메일을 보내려면 지금은: 응답 CSV를 내려받아 → 후원자 관리 › 잠재 후원자에서 **[+ 등록]** 또는 **AI 추출(붙여넣기)** 로 이름·연락처를 넣고 이벤트명(예: 서울추모식행사)을 적은 뒤 → 잠재 표에서 그 이벤트를 골라 **「✉ 이 이벤트 참여자에게 발송」** 을 누릅니다.
- 폼 설정에서 «응답자를 잠재 후원자로 자동 등록(이벤트명 지정)»을 켜 두면 이 과정을 자동으로 잇는 기능은 제안 단계입니다(2026-10-28).

## F-5. 자주 하는 실수

| 증상 | 원인 | 해결 |
|---|---|---|
| 주소는 열리는데 «접수 중이 아닙니다» | «발행»만 켜고 «활성»을 안 켬 | 폼 편집에서 활성 켜기 |
| 공유한 링크가 404 | slug를 나중에 바꿈 / 발행을 끔 | slug 원복 또는 새 주소 재공유 |
| 비회원이 로그인 화면으로 감 | 접근이 «회원만» 또는 «로그인 필수» | 접근을 «누구나»로 |
| 같은 사람이 두 번 못 냄 | «중복 응답 허용» 꺼짐(회원 기준) | 필요하면 허용 체크 |
| 응답 알림 메일이 안 옴 | 알림 이메일 주소 비어 있음 | 폼 편집에서 주소 입력(인앱 알림은 기본) |
| 저장 때 «블록에 이미지를 하나 이상 올려 주세요» | 이미지·자료 블록을 만들고 파일을 안 올림 | 파일을 올리거나 그 블록 삭제 |
| 한글(HWP) 파일이 «올릴 수 없는 형식» | 확장자가 없거나 다른 형식 | 파일 이름이 .hwp/.hwpx로 끝나는지 확인 · 안 되면 PDF로 저장해 올리기 |
