- 표 1개 = ILF 1개, API 1개 = 트랜잭션 1개(가중치 4). 정식 기능점수 산정이 아닙니다. 데이터는 실제 논리 파일 수보다 많게, 트랜잭션은 다기능 함수 때문에 적게 잡힐 수 있습니다.
