# 4단계 공통 결재 문서 설계서 (2026-11-06)

상태: 구현 중. 원문은 `막작업 파일/교사유가족협의회_결재시스템_설계도_문서작성화면.pdf`(2026-10-26, 15쪽)입니다.
Swain 지시: 설계도를 참고해 우리 시스템을 디벨롭한다. 기존 3단계에서 재원 선택과 번호 재사용을 함께 고칩니다(로드맵 §7).

## §1. DB

마이그는 3단계와 같은 `migrate-ledger-settlement`에 합칩니다(클릭 1회).

| 표 | 변경 |
|---|---|
| `approval_requests` | `doc_type`, `doc_no`, `version`, `body`, `form_data`, `form_version`, `pay_method`, `expense_kind`, `budget_split_id`, `approval_mode`, `substitute_basis_id`, `cancel_status`, `cancel_reason`, `cancel_requested_by`, `cancel_requested_at`, `delete_status`, `deleted_at`, `deleted_by`, `delete_reason`, `submitted_at`, `hold_reason`, `att_leave_request_id`, `followup_due`. 상태값에 draft, recalled 추가 |
| `approval_request_steps` | `version`, `kind`(approval·cancel), `step_type`(approve·consult), `assignee_id`, `assignee_name`, `assignee_title`. 유일 조건을 (문서, 버전, 종류, 순서)로 변경 |
| 신규 | `approval_doc_versions`, `approval_doc_references`, `approval_doc_files`, `approval_doc_watchers`, `approval_doc_comments`, `approval_doc_sequences`, `approval_saved_lines`, `approval_purge_grants`, `approval_purge_log`, `approval_form_guides` |

기존 결재 7건은 `doc_type='expense'`로 그대로 보이고 번호를 소급 발급합니다.

## §2. API

`/api/admin-docs` 하나로 처리합니다. 조회는 `view`, 쓰기는 `action`으로 나눕니다. 돈 처리(`admin-approval-pay`, `admin-approval-refund`)는 그대로 씁니다.

`/api/admin-docs-file?id=`는 문서 열람 권한을 확인한 뒤 1분짜리 다운로드 주소로 보냅니다.

## §3. 화면

사이드바에 **내부결재** 묶음을 둡니다: 결재 홈, 문서 작성, 내 문서함, 결재 문서함, 지출완료 확인, 예산 진행현황, 취소 및 보존함, 결재선 및 양식 설정.

근태 휴가 신청은 내부결재로 안내합니다. 이미 대기 중인 옛 신청은 근태 화면에서 그대로 처리됩니다.
