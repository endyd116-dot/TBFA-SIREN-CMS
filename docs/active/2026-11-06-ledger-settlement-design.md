# 3단계 결산과 2027 편성 설계서 (2026-11-06)

상태: 구현 완료. [1단계](2026-11-06-ledger-foundation-design.md), [2단계](2026-11-06-ledger-flow-design.md)에 이어집니다.
범위: 정관 제33조 제출 서류와 공익법인회계기준 재무제표를 장부에서 만들고, 다음 해 사업계획·수지예산을 같은 묶음으로 냅니다.

## 한눈에 보기

| 제출 서류 | 근거 | 숫자 출처 | 사람이 쓰는 부분 |
|---|---|---|---|
| 재무상태표 | 회계기준 별지 1호 | 장부 자동 | 없음 |
| 운영성과표 | 회계기준 별지 2호 | 장부 자동 | 없음 |
| 주석 17개 | 제41조, 제27조, 제30조 | 표는 자동 | 문구 편집 |
| 수지결산서 | 정관 제33조 | 장부 + 예산 | 없음 |
| 사업실적서 | 정관 제33조 | 집행액 자동 | 실적 문구, 횟수, 인원 |
| 재산목록 | 정관 제33조 | 장부 잔액 대조 | 명세 |
| 다음 해 사업계획서 | 정관 제33조 | 예산 자동 | 목표, 시기, 내용 |
| 다음 해 수지예산서 | 정관 제33조 | 예산 자동 | 없음 |

결산 순서: 작성 → 확정 → 감사 → 이사회 → 총회 → 제출. 확정하면 그해 장부가 닫히고 서류가 승인본으로 고정됩니다.

## §0. 결정

회계 처리 기준은 Swain 위임에 따라 Claude가 정했습니다(로드맵 §6-7). 외부 제출 전 세무사 1회 검토를 권합니다.

| # | 항목 | 결정 | 이유 |
|---|---|---|---|
| 1 | 공식 재무제표 출처 | 장부 하나. 재무 보고서의 운영성과표·재정상태표 탭과 PDF도 장부로 교체. 손익 현황은 운영 현황으로 유지 | 같은 이름 표에 숫자가 둘이면 안 됨 |
| 2 | 서식 | 별지 1·2호. 통합·공익목적사업·기타사업 3칸, 당기·전기. 전기 장부가 없으면 비교 생략 | 제10·23조, 부칙 제3조 |
| 3 | 당기운영이익 | 이월 전표 없이 보통순자산 잉여금에 계산해 표시 | 1단계 §1.3 |
| 4 | 부문 판단 | 전표 단위. 줄 하나라도 기타사업이면 전표 전체를 기타사업으로 집계. 섞인 전표는 점검표에 경고 | 줄 단위로는 현금 줄이 항상 공익으로 남아 부문별 대차가 안 맞음 |
| 5 | 임시 계정 | 잔액이 있으면 재무상태표에 «미정리»로 표시하고 확정을 막음 | 실무지침 |
| 6 | 수지결산서 | 수입은 계정, 지출은 관·항·목. 전기이월·차기이월은 현금성 자산. 차이는 «기타 자금 증감» 행으로 표시 | 장부가 발생주의라 현금 증감과 다름 |
| 7 | 전표 비용의 예산 목 판단 | 지출 연결 → 전표의 예산 줄 → 계정의 첫 연결 목 → 미배정 | 급여는 지출이 없고 전표뿐 |
| 8 | 집행 기준 보강 | 예산 대비 실적, 손익 현황, 다음 해 전년 실적에 «지출에서 오지 않은 비용 전표»(급여 등)를 더함 | 급여가 빠지면 화면끼리 숫자가 어긋남 |
| 9 | 수입 예산 | 수익 계정 기준 새 표. 예산 과목은 지출 전용이라 건드리지 않음 | 수지예산서에 수입이 필요 |
| 10 | 사업·활동·재원 예산 | 목 한 줄을 나누는 하위 표. 목 합계는 그대로 | 목당 한 줄 전제의 코드가 여러 곳 |
| 11 | 공통비 배분 | 배분 규칙 표(이름, 기준, 비율). 전표 나누기와 직원 인건비가 같은 규칙을 씀. 주석 17이 사용 중인 규칙을 표시 | 제30조 일관 적용 |
| 12 | 재산목록 | 명세는 사람이 쓰고 계정별 합계를 장부 잔액과 대조. 다르면 확정 불가. «장부 잔액으로 채우기» 제공 | 제출 서류가 장부와 달라지면 안 됨 |
| 13 | 확정 권한 | 확정·해제·승인 기록은 이사장 | 정관상 책임 |
| 14 | 승인본 | 확정 순간의 서류 전체를 저장. 이후 출력은 승인본. 해제하면 작성 상태로 돌아가고 이력에 남음 | 제출본과 화면이 달라지지 않게 |
| 15 | 시험 예산안 | 2027 예산안 14,788원을 이번 마이그에서 삭제 | 로드맵 §6-5 |
| 16 | 2026년 범위 | 11월 25일부터의 장부만 나옴. 서류에 범위를 명시 | Swain 결정 |

## §1. DB

마이그: `migrate-ledger-settlement` (`?run=1`, `?cleanup=1`)

| 표 | 내용 |
|---|---|
| `ledger_settlements` 신규 | `year` PK, `status`(draft·locked·audited·board_approved·assembly_approved·submitted), `checklist`, `snapshot`, 확정·감사·이사회·총회·제출 기록 |
| `ledger_notes` 신규 | `year`, `note_key`, `body` |
| `ledger_program_reports` 신규 | `year`, `program_id`, 계획(`plan_target`, `plan_period`, `plan_body`), 실적(`result_body`, `events`, `beneficiaries`) |
| `ledger_property_items` 신규 | `year`, `property_class`(basic·ordinary), `account_code`, `name`, `detail`, `quantity`, `amount`, `note` |
| `ledger_allocation_rules` 신규 | `name`, `basis`, `lines`(활동·사업·재원·비율), `is_active` |
| `budget_revenue_lines` 신규 | `plan_id`, `account_code`, `fund_id`, `planned_amount`, `prev_year_actual`, `note` |
| `budget_line_splits` 신규 | `line_id`, `function_code`, `program_id`, `fund_id`, `amount`, `note` |
| `budget_plans` | `carry_in` 추가 |
| `ledger_staff_allocations` | `rule_id` 추가 |

## §2. API

| 경로 | 권한 | 역할 |
|---|---|---|
| `GET /api/admin-ledger-statements` | finance_view | `doc=package`(서류 전체), `balance`, `operating`, `checks` |
| `GET·POST /api/admin-ledger-settlement` | 조회 finance_view, 체크 저장 finance_ledger_manage, 확정·해제·승인 기록은 이사장 | 결산 상태 |
| `GET·POST /api/admin-ledger-docs` | 조회 finance_view, 저장 finance_ledger_manage | 주석, 사업 실적·계획, 재산목록, 배분 규칙 |
| `GET·POST /api/admin-budget-plan-extras` | 조회 finance_view, 저장 finance_bookkeeping | 수입 예산, 목 나누기, 전기이월 |

수정: 재무 보고서 PDF, 예산 대비 실적, 손익 요약, 예산안 작성(전년 실적), 자동 전표(급여 배분 규칙), 전표 창(배분 규칙 적용), AI 도구.

## §3. 화면

- 장부 › **결산** 탭: 점검표, 재무상태표, 운영성과표, 주석, 수지결산서, 사업실적서, 재산목록, 사업계획·수지예산, 확정·승인. 문서마다 인쇄·엑셀, 전체 묶음 인쇄.
- 장부 › 기준 정보 › **배분 규칙** 추가, 인건비 배부에서 규칙 선택.
- 예산 관리 편성 화면: 수입 예산, 목 나누기, 전기이월, 수지 합계.
- 재무 보고서: 운영성과표·재정상태표 탭이 장부 기준으로 바뀜.

## §4. 검증

- 로컬 임시 DB: 두 회계연도 시나리오로 대차 일치, 전기 비교, 순자산 변동과 재무상태표 일치, 성격별 합계와 운영성과표 일치, 수지 맞음, 재산목록 대조, 확정·해제, 승인 순서, 승인본 고정, 배분 규칙 반올림.
- 라이브: 2099 시험 연도로 시나리오를 돌리고 `?cleanup=1`로 정리. 숫자 변화 없음 확인.

## §5. 한계

- 재무상태표 기타사업 칸은 전표 단위 판단입니다.
- 수지결산서 서식은 법령 서식이 없어 일반 형식으로 만들었습니다. 주무관청 양식이 있으면 맞춰야 합니다.
- 감가상각, 퇴직급여충당부채, 미지급비용, 선급비용 정리는 자동이 아닙니다. 점검표에서 확인하고 대체 전표로 입력합니다.
