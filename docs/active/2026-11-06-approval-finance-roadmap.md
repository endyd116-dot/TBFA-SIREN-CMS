# 내부결재 설계도 × 기존 재정 시스템 분석과 개발 방향 (2026-11-06)

상태: **0·1단계 완료**([1단계 설계서](2026-11-06-ledger-foundation-design.md)). 다음은 2단계 돈의 흐름 연결입니다. 아래 §6이 최신 결정입니다.
참고 문서: `막작업 파일/교사유가족협의회_결재시스템_설계도_문서작성화면.pdf`(2026-10-26), `docs/specs/교사유가족협의회_사단법인_예산시스템_기능설계도_v3.md`, `docs/specs/예산안-고도화-설계-v1.md`.
전제: 설계도를 그대로 구현하지 않고 참고만 합니다. 공익법인 신청 전에 개발합니다(Swain 2026-11-06).

## 1. 지금 재정 시스템의 실제 구조

| 기록 | 표 | 쓰는 곳 | 들어오는 경로 |
|---|---|---|---|
| 지출 | `expenses` | 손익, 예산 집행률(관·항·목), 전년 실적 | 결재 최종 승인, 직접 등록 + 이사장 승인, AI 도구 |
| 전표 | `vouchers` | 이상 지출 감지, 월말 체크, 예약액 | 통장 분류, 수동, 반복 전표, AI 도구 |
| 통장 | `bank_transactions` | 재정상태표, 현금흐름표 | 은행 파일 업로드 |
| 급여 | `payroll_slips` | 급여 화면만 | 재정과 연결 없음 |

확인된 문제:
1. 같은 돈이 세 곳에 따로 기록되고 서로 잇는 고리가 약합니다. 전표는 승인돼도 손익·집행률에 안 들어갑니다. 통장 수동 매칭 대상에 지출이 없습니다. 그래서 손익의 지출 합계와 현금흐름의 출금 합계가 맞을 수 없습니다.
2. 재무 보고서의 «예산 대비 실적» 화면·PDF(`admin-finance-budget-list`, `admin-finance-report-pdf`)는 옛 분류(`expense_categories`)로 조인합니다. 관·항·목으로 편성한 예산은 `category_id`가 비어 있어 표에서 빠집니다.
3. 결재로 만든 지출은 `category_id`가 없어 손익에서 항목명이 «기타», 코드가 null로 나옵니다(라이브 확인: 50.3만 원).
4. 최종 승인 처리에 트랜잭션이 없고 결의번호는 COUNT+1이며 유일 제약이 없습니다. 동시 처리 시 지출 중복·번호 중복이 가능합니다.
5. 인건비가 손익에 자동 반영되지 않습니다.
6. 사업·기능·재원 구분이 코드에 없습니다. 명세 v3의 4축 태깅이 구현되지 않았습니다.
7. 전표는 계정 하나에 금액 하나인 구조라 복식부기 장부가 아닙니다. 재정상태표도 통장 잔액 기반 간이판입니다.
8. 명세 v3는 «공익법인 미지정» 전제로 공시·구분·회계기준을 뺐습니다. 공익법인 신청으로 전제가 바뀌었습니다.

라이브 규모(2026-11-06 읽기 전용): 결재 7건, 올해 승인 지출 5건 약 62.6만 원, 통장 거래 4건(2026년 5월), 올해 전표 11건(5월 통장 파일에서 만든 작성중, 승인 0건), 2027 예산안 총액 14,788원 승인 상태(시험 데이터로 보임). 실제 회계는 시스템 밖에 있는 것으로 보입니다. 바꾸는 비용이 지금 가장 낮습니다.

## 2. 설계 원칙

1. **숫자의 기준은 하나.** 집행의 기준은 지출(`expenses`) 하나로 두고 전표·통장은 지출에 연결합니다.
2. **기존 19개 지출 참조 화면을 유지.** 지급 확인 시점에 지출을 만들어 집행률·손익 코드를 바꾸지 않습니다.
3. **예약은 새 잔액표를 만들지 않습니다.** 승인 완료·미지급 문서 합으로 계산하고, 원장은 이력 기록 전용으로 둡니다.
4. **문서 화면과 돈 처리를 분리.** 돈 처리는 공용 모듈 하나로 만들어 화면이 바뀌어도 다시 고치지 않습니다.
5. ~~SIREN은 결재·집행·증빙·사업별 집계, 공식 장부와 세무 신고는 세무사.~~ **Swain 결정으로 변경: 실제 장부가 없으므로 SIREN에 최초 구축한다(§6).**

## 3. 설계도 항목별 적용

| 구분 | 항목 |
|---|---|
| 그대로 채택 | 문서 5종 통합, 결재·합의 순차, 승인본 고정, 문서 참조, 원결재선 취소, 일반 삭제·보존, 상태값 분리, 예약과 집행 분리 |
| 바꿔서 채택 | 지출완료 체크는 통장 출금과 연결, 예산 원장은 이력 전용, 예산 선택은 관·항·목 + 사업·기능·재원, 결재선은 금액별 추천선 제공, 연차·병가는 근태와 연결, 지급 계좌는 거래처 재사용 |
| 미룸 | 카드 승인 갈음(규정 시행일 미정), 완전삭제(법정 보존기간 확인 전), 분할 지급·여러 예산 배분, 고정비·긴급 지출 자동 차단(처음엔 경고) |
| 하지 않음 | 별도 전결 판정, 병렬합의, 대결·후결, 자동이체 |
| 설계도에 없어 추가 | 통장 ↔ 지출 연결, 급여 → 인건비 지출, 수입 재원 구분, 80% 지표, 모금·활용 공개, 세무사 전달 파일, 결산 마감 잠금, AI 재정 도구 경로 정리 |

## 4. 단계

- **0단계 숫자 바로잡기:** 예산 대비 실적을 관·항·목으로 교체, 결재 지출 항목 표시, 승인 처리 묶음 처리와 결의번호 유일화. DB 변경 최소.
- **1단계 돈의 기준 통일:** 승인=예약, 지급 확인=지출 생성, 통장 출금 후보 자동 연결과 사무국장 확인, 지출 확정 시 전표 자동 연결, 결재 없는 출금 목록, 급여 확정 시 인건비 지출, 사업·기능·재원 입력(예산 목 기본값).
- **2단계 공통 결재 문서:** 임시저장·상신·회수·승인본 고정, 결재·합의, 문서함, 참조, 다중 첨부와 열람 권한, 지출결의서 이전과 품의서, 내부결재와 근태 연결, 원결재선 취소, 보존함, 카드·인감 문서.
- **3단계 공익법인 대응:** 고유목적사업 지출 비율 지표, 기부금 모금·활용 공개(투명성 페이지 + 어드민 관리), 결산서류 공시 자료와 주무관청 결산서, 세무사 전달 파일, 전용계좌 대조, 결산 마감 잠금. 지정 뒤 영수증 서식 전환(`lib/pdf-receipt.ts` 주석에 준비됨).

## 5. Swain 확인 필요

1. 공식 장부를 어디에 둘지(세무사·외부 프로그램 유지 추천).
2. 공익법인 신청 목표 시점.
3. 결재선: 기안자 지정 + 금액별 추천선 / 설계도 그대로 / 금액 자동 유지.
4. 연차·병가 창구: 내부결재 통일 / 근태 유지.
5. 결재 없는 지출: 입구 유지 + 표시 / 차단.
6. 2027 예산안 14,788원 승인 건이 시험 데이터인지.

법령 기준(80% 지출, 공시, 전용계좌, 보존기간)은 세무사 확인 후 설정값으로 넣습니다. 개발자가 임의로 정하지 않습니다.

## 6. Swain 결정 (2026-11-06) — 이 절이 위 §4·§5보다 우선

1. 실제 장부가 없다. SIREN에 최초 구축한다.
2. 공익법인 신청 목표는 2027년 3월이다.
3. 0단계 진행 승인.
4. 추천대로: 결재선은 기안자 지정 + 금액별 추천선, 연차·병가는 내부결재로 통일, 결재 없는 지출은 입구를 두고 표시.
5. 2027 예산안 14,788원은 시험 데이터다. 승인 상태라 화면에서 지울 수 없고 같은 연도 예산안을 새로 만들 수 없으므로, 실제 2027 예산 편성 전에 1회용 마이그로 정리한다.
6. 2026년 장부는 숭고한 등불 캠페인 이후 거래부터 기록한다. 그 전 돈은 시작일 잔액을 개시 전표 한 장으로 넣는다.
7. 세무 전문가가 없다. 회계 처리 기준은 Claude가 공개 기준으로 정한다(설계서 §0.2). 결산서를 외부에 내기 전 세무사 1회 검토를 권고했다.
8. 사업 목록은 먼저 만들고 어드민에서 고친다. 명세 v3의 5개 사업은 근거가 없어 쓰지 않고 홈페이지 기준 6개로 시작한다.
9. 사단법인 통장(우리은행)을 공익법인 전용계좌로 쓴다.

### 바뀐 순서

장부가 시스템에 없고 신청 서류에 결산서·예산서가 필요하므로(세무사 확인 필요), 2026년 결산을 시스템에서 만들 수 있어야 합니다. 문서 결재보다 장부와 결산이 앞섭니다.

| 순서 | 단계 | 내용 | 목표 |
|---|---|---|---|
| 0 | 숫자 바로잡기 | 예산 대비 실적, 결재 지출 항목, 승인 중복 방지 | 완료 |
| 1 | 장부 뼈대 | 복식 전표(차변·대변), 계정과목표, 사업·기능·재원, 마감 잠금, 변경 이력 | 완료 |
| 2 | 돈의 흐름 연결 | 후원·회비·기타 수입 자동 전표, 승인=예약, 지급 확인=지출·전표, 통장 출금 연결, 급여 자동 전표, 결재 없는 출금 표시 | 12월 |

### Swain에게 필요한 것

- 정관 별지 1(설립 기본재산 금액). 받은 정관 PDF에 없음
- 11월 25일 통장 잔액, 그 이후 통장 거래 파일과 증빙 보관 위치
- 회비·후원금 시행세칙(정관 제7조②)
- 후원금 운영재산 총회 승인(정관 제31조②2호), 정관 목적사업 변경 여부(제4조), 제6조①4호 검토
- 결산서를 외부에 내기 전 1회 검토해 줄 세무사
- 신청 분기 마감일 확인(분기별 마감이 있다는 2025년 자료가 있음)

회계 처리 기준은 Claude가 정하되, 세무확인과 서명은 대신할 수 없습니다. 근거와 한계는 설계서 §0.2·§0.4에 있습니다.
