# 회비 규칙 — 정기·일시 후원회원 자격과 결제사 입점 (2026-11-08)

상태: 구현·배포·라이브 캠페인 문구 갱신 완료(2026-11-08, 1회용 파일 삭제).
배경: KG이니시스 입점 심사에서 «후원 문구 불가, 회원회비로 수정», «결제일로부터 최대 1년, 회비 납부 후 회원 유지기간 확인», «월 정기결제 여부 확인»을 요구했다(2026-11-07). 결제사 규정상 한 번 결제로 제공하는 기간이 1년을 넘지 않아야 일반 가맹점으로 받아 준다. 법이 정한 유지기간은 없다.

## 결정 (Swain 2026-11-08)

| 항목 | 결정 |
|---|---|
| 명칭 | «정기 후원회원», «일시 후원회원» 그대로. 결제사에 보내는 상품명만 «교사유가족협의회 (정기) 회원회비» |
| 정기 후원회원 | 매월 자동결제(카드·계좌). 내는 동안 회원 자격 유지. 해지하거나 결제 실패 3회로 자동 해지되면 그 달로 종료 |
| 일시 후원회원 | 한 번 납부. 납부일부터 1년간 회원 자격. 만료 30일 전 안내, 다시 내면 그날부터 1년 |
| 최소 금액 | 둘 다 1만 원(종전 1,000원). 금액 선택 단추와 등불 사다리는 1만 원부터라 그대로 |
| 재가입 | 없음. 다시 내면 그날부터 회원 |
| 검토했다가 접은 안 | 모두 1개월(일시 큰 금액이 한 달 만에 끝남), 금액 비례(1만 원당 1개월 — 공평하지만 복잡) |

정관 제6조⑤·제7조는 후원회원의 돈을 «후원금»이라 부르고 유지기간이 없다. 자동 종료는 자격 «박탈»(제8조, 이사회 의결)이 아니라 회비가 정한 **유효기간 만료**로 시행세칙(제7조②)에 적는다. 시행세칙 초안은 `막작업 파일/교사유가족협의회_회비_시행세칙_초안.docx`(저장소 밖).

## 검증

로컬 임시 DB(실제 코드 묶음) 18개 통과: 11개월 전 일시 납부 → 유효, 13개월 전 → 잠재(잠재 행·사유 «회원 자격 만료»), 정기 활성 → 정기, 해지 뒤 13개월 → 잠재, 11개월 → 예비·해지, 만료일 = 납부일 + 12개월, 일괄 재평가, 만료 30일 전 안내는 그날 회원에게만(탈퇴·정기·유효기간 중 제외), 문구 3종.

## KG이니시스 회신 요지

상품명 «회원회비»로 통일(회원 종류 명칭 «후원회원»은 정관상 명칭이라 유지 가능 여부 문의), 유지기간은 일시 결제일부터 12개월·정기 결제월 1개월(매월 갱신), 월 정기결제는 빌링키 방식으로 진행하므로 정기결제 서비스 함께 신청. 결제사가 다음에 물을 수 있는 것: 회비 규정(시행세칙), 정기결제 약관, 환불 규정(정관 제7조③ 반환 불가·과오납 예외 → 시행세칙에 중복·착오 결제와 7일 이내 요청 환불 기준 권장).

## 남은 일

- KG이니시스로 계약하면 결제 연동을 새로 만들어야 한다(지금 코드는 KICC 이지페이 전용: 결제창·승인·정기결제·입금 통보). KICC 심사가 막힌 이유 확인 뒤 결정.

- 후원회원 안내 페이지·FAQ(어드민 콘텐츠)에 자격 규칙 문장 추가는 운영자가 어드민에서.
